# Ice Cream Game — 모바일 머지 게임 데모 (비공식 포트폴리오)

> ⚠️ **비공식 개인 포트폴리오 시연물입니다.** 배스킨라빈스, 카카오톡, LINE Pay 등 어떤 브랜드·서비스와도 공식 프로젝트나 제휴 관계가 아닙니다.
> 실제 결제·쿠폰 발급·쿠폰 사용·공유 보상·개인정보 수집은 일어나지 않습니다. 화면 이미지는 AI로 생성한 콘셉트 리소스이며, 브랜드 표기는 시연용 예시입니다.
> 모든 화면 하단에도 같은 고지가 표시됩니다.

물리 엔진(matter-js)으로 동작하는 **아이스크림 머지 퍼즐** 웹 데모입니다. 같은 단계의 스쿱 두 개가 부딪히면 한 단계 위 스쿱으로 합쳐지고, 점수 구간(500 / 1,000 / 1,500점)에 따라 할인 쿠폰 1장이 자동 발급됩니다.

## 실행

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm run build      # 타입체크 + 프로덕션 빌드 → dist/
npm run preview    # 빌드 결과 확인 (http://localhost:4173)
```

- 네트워크 없이 동작: 이미지(`public/assets`), 폰트(`@fontsource/jua`, 번들 포함), 게임 로직 모두 로컬. API·가입 없음.
- 휴대폰에서 보기: `npm run dev -- --host` 후 같은 Wi‑Fi에서 표시된 IP로 접속.

## 배포 (Railway)

GitHub 저장소를 Railway에 연결하면 자동으로 설치 → 빌드 → 실행됩니다. 별도 설정 파일은 필요 없습니다.

- 빌드: `npm run build` (Railway가 자동 감지)
- 실행: `npm start` → `vite preview --host 0.0.0.0 --port $PORT`
- Node 22 이상 (`package.json`의 `engines`)
- `vite.config.ts`의 `preview.allowedHosts`로 Railway 도메인 요청을 허용합니다.

## 구조

```
src/
  App.tsx                 화면 전환, 지갑(남은 기회/공유 보상/보유 쿠폰) 상태, 공유 처리, 설정·리워드 모달
  assets/manifest.ts      ★ 모든 이미지 경로 (교체는 여기서)
  game/
    engine.ts             MergeGame: matter-js 월드, 120Hz 고정 스텝, 병합 큐, 위험선 판정, 캔버스 렌더
    levels.ts             ★ 스쿱 단계 데이터 (반지름·점수·스킨·회전·오라)
    geometry.ts           게임통 이미지 실측 비율 → 벽/바닥/위험선 좌표
  lib/rewards.ts          리워드 구간, 최고 구간 1개 산정, 진행률, 할인 계산
  lib/storage.ts          localStorage 지갑 (사생활 보호 모드 등에서 실패해도 메모리로 동작)
  lib/product.ts          데모 상품/옵션 가격
  screens/                Start / Game / Result / Checkout (+ 화면별 CSS)
  components/ui.tsx       이미지 버튼, 아이콘 버튼, 네이티브 <dialog>, 토스트, 푸터 고지
public/assets/            핸드오프 패키지에서 여백을 잘라 WebP로 최적화한 리소스 (총 ~2.5MB)
e2e/game.spec.ts          Playwright 시나리오
```

### 레이아웃 / safe area

- 시안 711×1536 중 상태바·홈 인디케이터 영역을 뺀 **711×1440 아트보드**를 기준으로, `--u = min(가용 폭/711, 가용 높이/1440)` 한 단위로 전체를 비율 축소합니다. 각 요소는 시안 좌표(`box(x, y, w, h)`)로 배치해 원본 배치를 유지합니다.
- 가용 영역 = 뷰포트 − `env(safe-area-inset-*)` (`viewport-fit=cover`). 배경만 화면 전체로 깔리고 UI는 노치·홈 인디케이터를 침범하지 않습니다.
- 배경 사진은 흐림 + 밝은 톤 오버레이로 레이아웃보다 튀지 않게 했습니다.
- 게임 필드는 `touch-action: none` + Pointer Events로 스크롤/줌 대신 드래그를 우선합니다.

### 물리

- 콜라이더는 이미지 실루엣 비율로 정의(스쿱=타원, 콘=타원+삼각형, 컵=타원+사다리꼴)해 화면 크기와 일치.
- 벽·바닥은 이미지가 아니라 `geometry.ts`에서 계산한 두꺼운 정적 바디(400u). 추가로 매 스텝 속도 상한과 경계 보정(최후 안전장치)을 둡니다.
- 병합: `collisionStart`/`collisionActive`에서 같은 단계 쌍을 찾아 두 바디를 `merging`으로 표시한 뒤 스텝이 끝나고 처리 → 한 바디가 두 번 병합되지 않음. 새 단계는 72% 크기에서 커지며 겹침 폭발을 줄입니다. 최고 단계끼리는 합쳐지지 않습니다.
- 위험선: 드롭 후 1.3초가 지난 스쿱의 윗면이 위험선보다 위에 2.6초 누적되면 종료 (경고 깜빡임 표시).

### 머지 단계 (스쿱 → 콘 → 컵)

| 단계 | 이미지 | 폭(월드 단위) | 콜라이더 | 생성 점수 |
| --- | --- | --- | --- | --- |
| 0 | 딸기 스쿱 | 124 | 타원 | (드롭) |
| 1 | 초코 스쿱 | 139 | 타원 | 9 |
| 2 | 쿠키앤크림 스쿱 | 154 | 타원 | 17 |
| 3 | 블루 스쿱 | 171 | 타원 | 30 |
| 4 | 피스타치오 스쿱 | 190 | 타원 | 50 |
| 5 | 딸기 콘 | 203 | 타원 + 삼각형 | 85 |
| 6 | 민트 콘 | 226 | 타원 + 삼각형 | 140 |
| 7 | 선데 컵 (최고 단계) | 268 | 타원 + 사다리꼴 | 260 |

- 같은 아이스크림은 항상 같은 크기입니다 (단계마다 이미지 1개 · 크기 1개).
- 드롭되는 건 작은 스쿱 3종(딸기 45% / 초코 33% / 쿠키앤크림 22%)뿐이고, 최고 단계끼리는 합쳐지지 않아 통이 차면 끝납니다.
- 콘·컵은 원이 아니라 이미지 실루엣에 맞춘 복합 콜라이더(볼록 파트 조합)라 쓰러지거나 굴러갈 수 있습니다.
- 자동 플레이 6판 기준: 48~102번 드롭 후 종료, 875~2,774점.
- 망고 콘·BR 컵은 8단계 개편으로 제외 (이미지·콜라이더는 남겨둠).
- 쿠키앤크림·블루·피스타치오 스쿱은 받은 이미지의 흰 배경을 잘라내 사용했습니다.

이미지 교체·단계 추가는 `src/game/levels.ts`에서 `src`, `width`, `aspect`(높이/폭), `shape`(이미지 비율 좌표의 콜라이더)만 바꾸면 됩니다.

### 게임 규칙 (데모 설정)

- 참여 기회 기본 3회, 결과 화면의 공유 CTA로 **최대 1회** 추가. 설정(⚙︎) → "데모 데이터 초기화"로 리셋.
- 쿠폰은 1장만 보유하며 더 높은 구간을 달성했을 때만 상위 금액으로 승급(중복 발급 없음).
- 다음 체인지(3회): 현재 스쿱을 NEXT로 교체. 스페셜 아이템(1회): 통 안의 가장 작은 두 단계 스쿱 제거.
- 공유: 실제 카카오톡 SDK는 앱 키·도메인 등록이 필요해 연동하지 않았습니다. Web Share API(지원 시) → 클립보드 복사 순으로 대체하며, 공유 시트를 닫으면(취소) 보상이 지급되지 않습니다.
- 결제하기: 확인 모달과 "주문 완료(데모)" 표시만 하며 어떤 결제 요청도 보내지 않습니다.

### 디버그 훅

`?debug=1`(또는 dev 서버)에서 `window.__ICG__.game`으로 엔진에 접근할 수 있습니다 (`debugSpawn(level, x, y)`, `debugAddScore(n)`, `debugGameOver()`). E2E 전용이며 일반 플레이에는 영향이 없습니다.

## 리소스 메모

- 핸드오프 패키지의 `00_REFERENCE_SCREENS` 4장을 배치 기준으로 삼았고, `08_SOURCE_SHEETS`는 사용하지 않았습니다.
- CTA는 `04_BUTTONS/BACKGROUNDS` + `IMAGE_TEXT`를 겹쳐 구현했고(접근성 이름은 숨김 텍스트), 아이콘·수량이 함께 들어가는 보조 버튼, 공유 버튼, "아이스크림 떨어뜨리기"(세로 비율이 달라 늘리면 왜곡됨)는 CSS/텍스트로 처리했습니다.
- `07_OPTIONAL_COMPOSITE_REFERENCES`의 아이템 아이콘은 숫자·라벨을 제외한 그림 부분만 잘라 쓰고, 남은 횟수와 라벨은 DOM 텍스트로 렌더합니다.
- 점수·리워드·진행률·가격·남은 횟수 등 모든 동적 수치는 실제 DOM 텍스트입니다.
